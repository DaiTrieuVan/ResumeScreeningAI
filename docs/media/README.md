# Demo media

Thư mục này dành cho ảnh và tài nguyên truyền thông của Resume Screening AI.
Không đưa CV thật, email, số điện thoại, API key hoặc dữ liệu tuyển dụng riêng
tư vào ảnh/video.

## Tên tệp chuẩn

- `recruiter-workspace.png`
- `candidate-evidence.png`
- `real-jobs-matching.png`
- `career-gap-advisor.png`

## Quy cách đề xuất

- Chụp từ đúng release tag và dùng dữ liệu tổng hợp/ẩn danh.
- Ảnh PNG hoặc WebP, chiều rộng khoảng 1440-1920 px.
- Cắt tab trình duyệt, bookmark, thông báo và thông tin tài khoản không cần thiết.
- Nén ảnh trước khi commit; mỗi ảnh nên nhỏ hơn 1 MB nếu có thể.
- Video 15 phút nên tải lên YouTube/Drive công khai hoặc đính kèm GitHub Release,
  sau đó cập nhật URL trong `README.md`.
