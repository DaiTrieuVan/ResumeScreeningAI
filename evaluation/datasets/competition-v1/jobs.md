# Synthetic job descriptions

## backend-engineer

Build Python/FastAPI services and REST APIs; use SQL, Git and automated tests. Python and REST API evidence are mandatory. Two years of software experience is preferred.

## data-analyst

Analyze operational data with SQL and Python, explain findings to non-technical partners and create reproducible dashboards. SQL is mandatory; statistics and visualization are preferred.

## product-owner

Own a product backlog, translate customer needs into acceptance criteria and coordinate an agile delivery team. Backlog ownership and stakeholder communication are mandatory.
